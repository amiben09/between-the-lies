# Read first
The active Between the Lies studio is on branch **`studio`** of this repo, not `main`:
`git fetch --depth 50 origin studio && git checkout studio`, then read `CLAUDE.md` and `docs/STUDIO_MEMORY.md` there.
Rule: every finished video is committed to `videos/` on `studio` and pushed (cloud machines are wiped between sessions).
`main` = earlier v0.2 system; don't overwrite it.
